# 打包配置说明

## 当前配置（Apple Silicon）

## Electron 下载失败（EOF）如何处理

- 默认已启用 **Electron 镜像**（`https://npmmirror.com/mirrors/electron/`），用于解决打包时从 GitHub 下载 Electron 经常 EOF/超时的问题。
- 如需切回官方源，可在打包前显式执行：

```bash
ELECTRON_MIRROR="" pnpm run build
```

### package.json 配置

当前 `package.json` 中的 `build.mac.target` 配置为：

```json
"arch": ["arm64"]
```

仅创建 Apple Silicon（arm64）版本，不再构建 Intel 或 universal 版本。

### 打包命令

1. **默认打包**（创建 arm64 的 DMG 和 ZIP）：
   ```bash
   pnpm run build
   # 或
   ./ninja/build.sh
   ```

2. **只打包 DMG**：
   ```bash
   pnpm run build:dmg
   # 或
   ./ninja/build.sh --dmg
   ```

3. **只打包 ZIP**：
   ```bash
   pnpm run build:zip
   # 或
   ./ninja/build.sh --zip
   ```

4. **显式打包 ARM64 版本**：
   ```bash
   pnpm run build:arm64
   # 或
   ./ninja/build.sh --arm64
   ```

## DMG 附加文件

`ninja/build.sh` 会先将以下文件复制到独立的 `.dmg-staging/` 暂存目录，再由 electron-builder 写入 DMG；构建脚本退出时清理该目录，不会覆盖或删除项目根目录的 `README.md`。

| 源文件 | DMG 内显示 | 作用 |
|--------|------------|------|
| `docs/README.md` | `README.md` | 安装与解锁说明（中英双语） |
| `docs/提示损坏？点我.command` | `提示损坏？点我.command` | 一键 `xattr -cr` 解除隔离属性 |

布局在 `package.json` → `build.dmg.contents`：左上 App、右上 Applications 链接、左下 README、右下解除脚本。

## 注意事项

- `--x64` 和 `--universal` 参数已停止支持，使用时会提示错误
