# Nigate ガイド

## アプリと安全性

Nigate は Swift と SwiftUI で作られたネイティブ macOS アプリです。macOS 14 以降が必要です。macOS のディスクサービスで NTFS パーティションを検出し、MacFUSE と `ntfs-3g` で読み書きマウントを行います。

マウント、修復、フォーマットはディスク上のデータに影響することがあります。重要なファイルを事前にバックアップし、転送中にデバイスを取り外したりアプリを強制終了したりしないでください。`ntfsfix` の修復範囲は限られており、Windows の `chkdsk` の代替ではありません。

アプリは Gatekeeper を無効にしたり、システム全体のセキュリティ設定を変更したりしません。MacFUSE やシステム拡張をインストールするときは、macOS の案内に従い、信頼できる配布元であることを確認してください。

## 初回起動と依存関係

1. 「依存関係」画面を開き、「依存関係を確認」を選択して、macOS、Xcode Command Line Tools、Homebrew、MacFUSE、`ntfs-3g`、任意の `fswatch` の状態を確認します。
2. 読み書きマウントには macOS 14 以降、MacFUSE、`ntfs-3g` が必要です。その他の項目の用途や必須かどうかは一覧に表示されます。
3. 「ワンクリックインストール」でターミナルからインストールを開始するか、各項目を展開してコマンドを確認・コピーし、手動でインストールできます。システム拡張の承認は macOS の案内に従ってください。
4. インストールまたは承認後、依存関係を再確認します。MacFUSE と `ntfs-3g` が利用可能になるまで、NTFS の読み書きマウントなどは行えません。

## デバイスと操作

NTFS ドライブを接続すると、Nigate はスキャンして「NTFS デバイス」画面に認識したボリュームを表示します。カードにはボリューム名、デバイス識別子、マウントポイント、空き容量/合計容量が表示されます。「更新」で再スキャンできます。上部の一括操作から、対象デバイスを読み書きマウント、読み取り専用へ復元、アンマウント、取り出しできます。

### アイコンの見方

- **画面切り替え**：パズルは「依存関係」、ドライブは「NTFS デバイス」、クエスチョンマークは「ヘルプ」、歯車は「設定」です。
- **タイトルバー**：コーヒーカップはスリープ防止モードの切り替えです。盾を 3 秒間長押しすると状態保護を切り替えます。電源はアプリ終了、情報アイコンは「このアプリについて」、太陽/月は外観の切り替えです。
- **状態ランプ**：緑はデバイスを認識し、読み取り専用のボリュームがない状態です。オレンジは必須依存関係の不足、または読み取り専用ボリュームがある状態です。グレーは NTFS デバイスが未認識です。
- **デバイス操作**：円形の矢印は更新、鉛筆は読み書きマウント、目は読み取り専用への復元、取り出し記号はアンマウント、×印付きドライブは取り出し、レンチとドライバーは修復、テキストカーソルは名前変更、内蔵ドライブはフォーマット、曲がった矢印はリセットです。カードのドライブアイコンは緑が読み書き、オレンジが読み取り専用を示します。各アイコンの横には操作名も表示されます。

- **読み取り専用**：ファイルを読み取れますが変更できません。Windows の高速スタートアップや休止状態によってファイルシステムが安全でない状態になる場合があります。その場合は Windows を完全に終了してから Mac に接続してください。
- **読み書きマウント**：「読み書き」を選び、管理者操作を承認します。既存のマウントを解除してから `ntfs-3g` でマウントします。使用中のアプリを先に終了してください。
- **読み取り専用へ復元**：読み書きマウントを解除し、macOS に読み取り専用で再マウントさせます。手動で選択すると、自動マウントがその接続中に読み書きへ戻すことを一時的に防ぎます。
- **アンマウント**：ファイルシステムのマウントを解除しますが、デバイスは接続されたままです。再度使うには一覧を更新してマウントします。
- **取り出し**：macOS にデバイスの取り出しを依頼します。システム操作の成功を待ってから取り外してください。先にドライブを使用中のアプリを終了します。
- **リセット**：デバイス使用中エラーの解消に使います。パーティションをアンマウントし、`ntfsfix` を実行してから読み取り専用で再マウントを試みます。管理者認証が必要で、修復にはデータ損失のリスクがあります。
- **修復**：`ntfsfix` で限定的な修復を行い、元のマウントモードへの復元を試みます。失敗した場合はエラーを記録し、重要なデータに対して修復を繰り返さないでください。
- **名前変更**：新しいボリュームラベルを入力します。アンマウント後、NTFS ラベルとパーティション名を更新し、元の読み取り専用または読み書きモードに戻します。名前は1～32文字で、`\\ / : * ? " < > |` は使用できません。操作中はファイルを転送しないでください。

### アンマウントと取り出しの違い

| 操作 | ファイルシステムのマウント | デバイス接続 | 再利用 |
| --- | --- | --- | --- |
| アンマウント | 解除 | 接続したまま | 更新して再マウント |
| 取り出し | デバイスとともに解除 | システムに切断を依頼 | 再接続して使用 |

アンマウントは安全な取り外しと同じではありません。取り外す前に「取り出し」を選び、完了を待ってください。

## フォーマット

フォーマットはディスク全体のすべてのパーティションとデータを消去し、取り消せません。選択したボリュームだけではなく、ディスク全体を GPT パーティションマップと NTFS ファイルシステムで再構成します。先にバックアップし、対象ドライブと容量を確認してください。

安全のため、macOS が対象を外付けの物理ディスク全体と確認し、起動ディスクでも内蔵、仮想、ディスクイメージ、合成デバイスでもないと確認できる場合だけ実行できます。デバイス、パーティション、プロトコルの情報は存在し、一致している必要があります。情報の欠落、未知、矛盾がある場合は拒否されます。フォーマット中は取り外し、電源オフ、強制終了をしないでください。

## 自動読み書き

スキャン時に**マウント済みで現在読み取り専用**の NTFS ボリュームを読み書きへ自動で切り替えます。ウィンドウを開く必要はありません。未マウント、すでに読み書き、または認識できないデバイスは対象外です。自動マウントでも管理者認証が必要になる場合があります。

手動で読み取り専用へ戻すか「リセット」を実行すると、その接続中は手動で読み取り専用にしたデバイスとして記録され、直ちに読み書きへ戻りません。その後、手動で読み書きマウントすると選択が解除されます。

## スリープ防止と状態保護

タイトルバーのコーヒーカップアイコンをクリックすると、**オフ → スリープ防止 → スマートスリープ防止 → オフ** の順に切り替わります。既定はスマートスリープ防止です。状態保護中はこのボタンがロックされます。

- **オフ**：アプリはシステムのスリープを防止しません。
- **スリープ防止**：アイドル時も継続してスリープを防止します。長時間の作業に使えます。
- **スマートスリープ防止**：マウント済みディスクだけを監視します。ディスク活動中はスリープを防止し、活動停止から約20秒後に再び許可します。マウント済みディスクがなければ継続的には防止しません。

アプリ終了時にスリープ防止は停止します。タイトルバーの盾を3秒間長押しすると状態保護を有効/解除できます。誤操作を防ぐ機能であり、故障やデータ損失からディスクを保護するものではありません。

## 設定

「設定」では、管理者パスワードを macOS Keychain に保存するか、ログイン時に起動するか、起動時の画面、表示言語、外観、ボタンのヒント表示を設定できます。ヒント表示は初期状態ではオフです。パスワード保存を有効にした場合のみ Keychain に保存されます。いつでも無効化または保存済みパスワードの削除ができます。

ウィンドウを閉じてもアプリは終了せず、メニューバーに残ります。メニューバーのアイコンから主ウィンドウを開いたり、NTFS デバイスを管理できます。言語と外観は自動保存されます。スリープ防止はタイトルバーからも操作できます。

## トラブルシューティング

### ボリュームが読み取り専用になる

macOS は NTFS を標準で読み取り専用マウントします。「依存関係」画面で MacFUSE と `ntfs-3g` が利用可能であることを確認してから「読み書き」を選びます。Windows の高速スタートアップや休止状態を使った場合は、Windows に接続して完全に終了してから再試行してください。

### マウントが失敗またはタイムアウトする

依存関係を再確認し、ドライブを使用中のアプリを終了して、管理者認証を確認してください。Windows が正常に終了していない場合もファイルシステムに不整合が生じます。タイムアウト後は一覧を更新してから再試行し、ファイル転送中に繰り返さないでください。

### `Resource busy` エラー

Finder のウィンドウとボリュームを使用中のアプリを閉じ、デバイスカードの「リセット」を選びます。パーティションをアンマウントし、`ntfsfix` を実行して読み取り専用での再マウントを試みます。管理者認証が必要です。重要なデータは先にバックアップしてください。解決しない場合はエラーを記録してサポートを求め、不確かなディスク識別子に対して破壊的なターミナルコマンドを実行しないでください。

### 修復後も読み書きできない

`ntfsfix` の機能は限られており、一部のメタデータしか修復できないことがあります。Windows で管理者権限の `chkdsk` を実行して確認してください。重要なデータにアクセスできない場合は書き込みを停止し、データ復旧を優先してください。

### macOS 更新後に MacFUSE が古い、または拡張がブロックされる

「依存関係」画面で MacFUSE を展開し、表示される手順で公式バージョンに更新します。「システム設定 → プライバシーとセキュリティ」で確認済みの拡張を承認してください。項目名は macOS のバージョンにより異なります。Gatekeeper を無効のままにしないでください。一時的なセキュリティ変更が手順に含まれる場合は、警告に従い作業後すぐに元に戻してください。

### アンマウント後にデバイスが見つからない

アンマウントはファイルシステムのマウントを解除するだけで、デバイスは接続されたままです。一覧を更新して再マウントできます。取り外すときは「取り出し」を使ってください。

詳細は[トラブルシューティングセンター](https://github.com/hoochanlon/Free-NTFS-for-Mac/issues/9)を参照してください。問題を報告するときは macOS バージョン、デバイス情報、操作内容、完全なエラーメッセージを記載し、パスワードや個人ファイルの内容は共有しないでください。
