# Nigate 指南手冊

## 關於與安全性

Nigate 是使用 Swift 和 SwiftUI 建立的原生 macOS 應用程式，需要 macOS 14 或以上版本。應用程式透過 macOS 磁碟服務偵測 NTFS 分割區，並使用 MacFUSE 與 `ntfs-3g` 提供讀寫掛載。

掛載、修復與格式化可能影響磁碟資料。請先備份重要檔案；檔案傳輸期間不要拔除裝置或強制結束應用程式。`ntfsfix` 只能處理部分 NTFS 問題，不能取代 Windows `chkdsk`。

應用程式不會停用 Gatekeeper，也不會修改全域安全性設定。安裝 MacFUSE 或系統延伸功能時，請依照 macOS 當下的提示操作，並確認安裝來源可信。

## 初次使用與依賴項目

1. 開啟「依賴」頁面並選擇「檢查依賴」，查看 macOS、Xcode Command Line Tools、Homebrew、MacFUSE、`ntfs-3g` 及選用的 `fswatch` 狀態。
2. 讀寫掛載需要 macOS 14 或更新版本、MacFUSE 與 `ntfs-3g`。其他項目的用途與必要性會顯示在清單中。
3. 可使用「一鍵安裝」在終端機啟動安裝流程，或展開依賴項目檢視及複製命令，手動安裝。系統延伸功能請依照 macOS 提示核准。
4. 安裝或核准後，請重新檢查依賴。MacFUSE 與 `ntfs-3g` 尚未就緒前，無法使用 NTFS 讀寫掛載及相關操作。

## 裝置與操作

插入 NTFS 存储设备后，应用会扫描并在“NTFS 设备”页显示已识别的分区。设备卡片显示卷标、设备标识、挂载点和可用/总容量。可用“刷新”重新扫描；顶部批量操作可对符合条件的设备执行挂载、恢复只读、卸载或推出。

### 图标说明

- **页面导航**：拼图表示“依赖”，磁盘表示“NTFS 设备”，问号表示“帮助”，齿轮表示“设置”。
- **顶部工具栏**：咖啡杯切换防止休眠模式；盾牌长按 3 秒切换状态保护；电源用于退出，信息图标打开“关于”，太阳/月亮切换外观。
- **状态圆点**：绿色表示已识别设备且没有只读卷；橙色表示缺少核心依赖或存在只读卷；灰色表示尚未识别到 NTFS 设备。
- **设备操作**：圆形箭头表示刷新；铅笔表示读写挂载；眼睛表示恢复只读；弹出符号表示卸载；带叉磁盘表示推出；扳手与螺丝刀表示修复；文本光标表示重命名；内置磁盘表示格式化；回转箭头表示重置。设备卡片的磁盘图标为绿色表示读写、橙色表示只读；操作图标旁也会显示文字名称。

- **唯讀**：可以讀取檔案，但無法修改。Windows 快速啟動或休眠可能使檔案系統處於不安全狀態；遇到此情況，請先在 Windows 完整關機，再連接至 Mac。
- **讀寫掛載**：選擇「讀寫」並授權管理員操作。應用程式會先卸載現有磁碟區，再透過 `ntfs-3g` 以讀寫模式掛載。請先關閉正在使用該磁碟區的應用程式。
- **還原唯讀**：移除讀寫掛載，並交由 macOS 以唯讀方式重新掛載。手動選擇後，自動掛載會暫時避免再次變更該磁碟區。
- **卸載**：移除檔案系統掛載，但裝置仍連接至 Mac。重新整理裝置清單後即可再次掛載。
- **退出**：要求 macOS 退出裝置。請等待系統操作成功後再拔除裝置；操作前請關閉正在使用磁碟的應用程式。
- **重設**：用於處理裝置忙碌等問題。應用程式會卸載分割區、執行 `ntfsfix`，再嘗試以唯讀模式重新掛載。需要管理員授權，修復仍有資料風險。
- **修復**：使用 `ntfsfix` 處理有限的檔案系統問題，之後嘗試還原原本的掛載模式。若失敗，請記錄錯誤，不要對重要資料反覆嘗試修復。
- **重新命名**：輸入新的磁碟區標籤後，應用程式會卸載裝置、更新 NTFS 標籤與分割區名稱，再還原原本的唯讀或讀寫模式。名稱須為 1 至 32 個字元，且不能包含 `\\ / : * ? " < > |`。操作期間請勿傳輸檔案。

### 卸載與退出的差異

| 操作 | 檔案系統掛載 | 裝置連線 | 再次使用 |
| --- | --- | --- | --- |
| 卸載 | 移除掛載 | 保持連線 | 重新整理後再次掛載 |
| 退出 | 隨裝置退出而移除 | 要求系統中斷連線 | 重新連接裝置 |

卸載不等同於安全拔除。準備拔除時請使用「退出」，並等待完成確認。

## 格式化

格式化會清除整個磁碟上的所有分割區與資料，且無法復原。Nigate 會將整個磁碟重新建立為 GPT 分割區表與 NTFS 檔案系統，不只是清除選取的磁碟區。請先備份，並確認目標磁碟及其容量。

基於安全考量，只有 macOS 確認目標為外接實體整顆磁碟、不是啟動磁碟，也不是內建、虛擬、磁碟映像或合成裝置時，才允許格式化。裝置、分割區與通訊協定資訊都必須存在且一致。資訊缺失、未知或矛盾時會拒絕操作。格式化期間請勿拔除裝置、關機或強制結束應用程式。

## 自動讀寫

應用程式會在掃描時處理**已掛載且目前為唯讀**的 NTFS 磁碟區，自動改掛為讀寫。視窗不必開啟。尚未掛載、已是讀寫或無法識別的裝置不會列入處理。自動掛載可能要求管理員授權。

手動還原唯讀或使用「重設」後，該裝置在本次連線期間會記錄為手動唯讀，不會立刻改回讀寫。之後手動執行讀寫掛載會清除此選擇。

## 防止睡眠與狀態保護

點擊標題列的咖啡杯圖示，可在 **關閉 → 防止睡眠 → 智慧防止睡眠 → 關閉** 之間循環。啟用狀態保護後，此控制項會鎖定。

- **關閉**：Nigate 不會防止系統睡眠。
- **防止睡眠**：持續防止閒置睡眠，即使磁碟閒置也會保持啟用，適合長時間作業。
- **智慧防止睡眠**：只監控已掛載的磁碟。偵測到磁碟活動時防止睡眠，活動停止約 20 秒後恢復允許睡眠。沒有已掛載磁碟時不會持續防止睡眠。

結束應用程式時會停止防止睡眠。長按標題列盾牌圖示 3 秒可啟用或解除狀態保護。此功能只用來防止誤操作，不能保護磁碟免於故障或資料遺失。

## 設定

「設定」頁可選擇是否將管理員密碼儲存於 macOS Keychain、登入時啟動、啟動時顯示的頁面、介面語言、外觀，以及是否顯示按鈕懸停提示。懸停提示預設關閉。只有啟用密碼儲存時，密碼才會存入 Keychain；可隨時關閉此選項或刪除已儲存的密碼。

關閉視窗時應用程式會留在選單列，不會結束。可透過選單列圖示開啟主視窗或管理 NTFS 裝置。語言與外觀設定會自動儲存。防止睡眠也可由標題列控制。

## 常見問題與疑難排解

### 為什麼磁碟區是唯讀？

macOS 預設以唯讀方式掛載 NTFS。請先在「依賴」頁確認 MacFUSE 與 `ntfs-3g` 已就緒，再選擇「讀寫」。若曾使用 Windows 快速啟動或休眠，請將磁碟接回 Windows 並完整關機後再試。

### 掛載失敗或逾時

重新檢查依賴，關閉其他正在使用磁碟的應用程式，並確認管理員授權成功。Windows 未正常關機也可能造成檔案系統不一致。逾時後先重新整理裝置清單再重試；檔案傳輸期間請勿反覆操作。

### 出現 `Resource busy` 錯誤

關閉 Finder 視窗及正在使用該磁碟區的應用程式，再選擇裝置卡片上的「重設」。Nigate 會卸載分割區、執行 `ntfsfix` 並嘗試以唯讀模式重新掛載，需要管理員授權。請先備份重要資料。若仍失敗，記錄錯誤並尋求支援，不要對不確定的磁碟識別碼直接執行具破壞性的終端機命令。

### 修復後仍無法讀寫

`ntfsfix` 的能力有限，可能只修復部分中繼資料。請在 Windows 以管理員權限執行 `chkdsk` 檢查磁碟。若重要資料無法存取，請停止寫入並優先進行資料救援。

### macOS 更新後 MacFUSE 過舊或延伸功能遭封鎖

在「依賴」頁展開 MacFUSE，依照頁面提供的步驟更新官方版本，並在「系統設定 → 隱私權與安全性」核准已確認的延伸功能。設定名稱可能因 macOS 版本而異。請勿長期停用 Gatekeeper；若步驟要求暫時變更安全設定，請遵守警告並在完成後立即還原。

### 卸載後在哪裡找到裝置？

卸載只會解除檔案系統掛載，裝置仍保持連接。重新整理清單即可再次掛載；準備拔除時請使用「退出」。

更多協助請參閱[疑難排解中心](https://github.com/hoochanlon/Free-NTFS-for-Mac/issues/9)。回報問題時請附上 macOS 版本、裝置資訊、操作步驟與完整錯誤訊息；請勿公開密碼或個人檔案內容。
